═══════════════════════════════════════════════════════════════════════════════
                          TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: "No API key found"
Solution: Add ONE_MIN_AI_API_KEY=sk-... to .env file

Problem: "JSON parsing error"
Solution: Try different seed: --seed 999

Problem: "Too slow"
Solution: Use original generator or reduce item count

Problem: "Connection timeout"
Solution: Check proxy settings in .env (NO_PROXY=localhost,127.0.0.1)
